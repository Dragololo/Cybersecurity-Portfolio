#### Running the Query

The question has two conditions that both have to be true, so I joined them with `AND` in a single `WHERE` clause.

```shell
MariaDB [employees]> SELECT last_name FROM employees WHERE first_name LIKE 'Bar%' AND hire_date = '1990-01-01';

+------------+
| last_name  |
+------------+
| —REDACTED— |
+------------+
1 row in set (0.035 sec)
```

**Breakdown:**

- `SELECT last_name` returns only the `last_name` column
- `FROM employees` reads from the `employees` table
- `WHERE` begins the filter that decides which records are returned
- `first_name LIKE 'Bar%'` keeps records whose `first_name` starts with `Bar`. The `%` wildcard matches zero or more characters, so names such as `Barbara` or `Bartek` fit
- `AND` requires both conditions to be true for a record to be returned
- `hire_date = '1990-01-01'` keeps records hired on exactly that date. The date sits in single quotes, like a string
- `;` terminates the query
- `1 row in set` confirms exactly one record satisfied both conditions

The line as a whole returns the last name of the one employee whose first name starts with `Bar` and who was hired on 1990-01-01.

> **Why it matters:** `AND` combines conditions so that every one of them must hold, which narrows the results down to a single record. The `LIKE` condition alone would return every employee whose first name starts with `Bar`, and the date condition alone would return everyone hired that day.
